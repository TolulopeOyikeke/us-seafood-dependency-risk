# U.S. Seafood Dependency Risk Index (U.S.-SDRI) Version 2.0.0

This repository contains the R workflow used to construct the U.S. Seafood Dependency Risk Index (U.S.-SDRI), generate manuscript tables, and produce figures for the study on species-specific seafood dependency risk in the United States.

The analysis integrates public data on U.S. seafood imports, exports, domestic commercial landings, and country-level vulnerability and readiness to characterize structural exposure across 22 core seafood groups from 2009 to 2023. The workflow is written so that the analysis start and end years can be changed in one location if a different study period is needed.

The workflow uses the following public data sources:

1. NOAA Fisheries Foreign Fishery Trade Data

## Main workflow

The complete analysis can be run from:

```text
us_seafood_sdri_workflow.Rmd
```

The workflow:

1. imports and cleans the NOAA trade, NOAA landings, and ND-GAIN data;
2. harmonizes trade products and landings records into common seafood groups;
3. constructs species-year import dependence, supplier concentration, and exporter-risk measures;
4. calculates the U.S.-SDRI and associated robustness outputs; and
5. generates tables and figures.

## Index overview

The U.S.-SDRI combines three species-year components:

1. **Export-adjusted import dependence** — the share of apparent species-specific supply attributable to imports after adjusting the domestic landings proxy for exports.
2. **Supplier concentration** — concentration of reported source-country import shares, measured using the Herfindahl-Hirschman Index (HHI).
3. **Exporter risk** — an import-share-weighted country-level measure combining ND-GAIN vulnerability and reverse-coded readiness.

Each component is min-max normalized using the analytical reference panel, and the final U.S.-SDRI is calculated as the geometric mean of the three normalized components.

The index is designed as a measure of structural external supply exposure. It is not a forecast of realized disruption and does not estimate the causal effect of individual trade, geopolitical, production, disease, climate, or logistics shocks.

The workflow uses the country geography reported in the NOAA/Census foreign-trade data to characterize sourcing concentration and exporter risk. It does not reconstruct the complete upstream harvest, production, processing, or intermediate-trade pathway of imported seafood.
